Ubuntu's own packages are now updated from the panel: all at once or one by one.

- **Software → Ubuntu updates:** every package waiting for an update is listed with its installed and new version and where it comes from (Ubuntu, `ppa:ondrej/php`, `apt.postgresql.org`…). Security updates are marked and on top. **Check now** refreshes the package lists.
- **Update all or update the selected ones:** "Update all" works like `apt upgrade`: no package is removed, configuration files changed by hand are kept, and it waits up to 10 minutes for apt to finish another operation. Selected packages are updated with `--only-upgrade`; a selection that would require removing a package is refused. Progress and the log appear in a dialog like other installations.
- **Serfex components:** when the package of a component such as Nginx, PHP or MySQL/PostgreSQL is updated, Serfex checks that component right away; if the check fails, the component's previous configuration is restored and it is restarted. The list says which package belongs to which component.
- **Ubuntu's decisions are respected:** held packages (`apt-mark hold`) and updates Ubuntu is phasing in are not updated. Kept-back packages can only be updated by selecting them one by one.
- **Reboot:** when a package such as a new kernel or OpenSSL needs a reboot, a notice appears on the page and on Overview saying which packages need it. **Restart** reboots the server one minute later; within that minute it can be cancelled with Undo.
- **Automatic security updates:** the state of Ubuntu's `unattended-upgrades` (on/off, security only or not, last run) is shown and can be turned on and off with Undo. Serfex does not change the default.
- **Overview → Updates:** the card now shows Ubuntu updates next to the Serfex version; a pending security update or reboot stands out as a problem.

Only full administrators can start updates; support and read-only administrators see the list.
