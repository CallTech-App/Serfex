- Panel certificate: the Let's Encrypt (or uploaded) certificate for the panel's name is now served only when the panel is opened with that name. A panel opened by IP address and port always uses Servik's own certificate. Before, as soon as the certificate arrived, a page open by IP silently stopped connecting and the setup wizard got stuck on a step. After the update the browser may show the first certificate warning once more when you open the panel by IP.
- When the panel cannot reach the server (the connection dropped or the browser refused it), a "The panel could not be reached" warning and a "Reload the page" button appear at the top instead of the button staying in a waiting state.
- Setup wizard, Name servers step: a site is also created for the domain you enter ("Create a site for …", on by default). The site belongs to the administrator, includes www, uses the default web server and PHP version, is added to Sites and uses the same DNS zone.
