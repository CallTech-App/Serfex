- **Connection details** in the site tools now work: the server's address and IP, the SFTP port and the site's FTP accounts (with the folder they open in), the site's databases (server, port, users, phpMyAdmin/Adminer link) and, when SSH is on, the `sftp`/`ssh` commands, on one page and ready to copy. Passwords are not shown (Serfex does not store them); each section links to the page where a new one is set. Customers can use it on their own sites too.
- In **Laravel → Scheduler** every task has its own switch: a task that is turned off is skipped when its time comes, and the application's code does not change. Undo turns it back on right away; a task that is off can still be run by hand with "Run now". When there is a task that is off, Serfex runs `schedule:run` through a small launcher (`/opt/serfex/laravel/schedule-run.php`); when none is off, it runs `php artisan schedule:run` directly as before.
- The Overview screenshots in the README were retaken with the new design.
- `composer.lock` was synced with `composer.json` (composer no longer warns). Livewire was upgraded to 4.4.8 (a medium-severity security advisory published for 4.4.7; Serfex did not use the affected `#[Authorize]` feature).
- The old Turkish update address left over from releases before 0.1.20 (`/ayarlar/guncellemeler/ilerleme`) was removed. When updating straight to this release from a release older than 0.1.20, the update page may show an error at the end; the update still completes, and reloading the page is enough.
- Fixed dates in the agent tests (9 places) are now calculated from today, so the tests do not break by themselves later.
