- Fix: in Software an installation could stay at "Installing" after it had finished and lock every other Install/Update button. The cause was Ubuntu's `needrestart` tool restarting the panel's queue worker after the PHP package the installation upgraded. Now `needrestart` leaves Servik's own services alone, and an operation cut off halfway is read from the installation log and closed automatically.
- Customer PostgreSQL is now installed from PostgreSQL's official repository (apt.postgresql.org) with the newest stable version (18 today; Ubuntu's 16 before). The port is always 5432; the panel's own database stays on 5433. An installed server stays on its major version; minor releases (for example 18.1 → 18.2) are installed with "Update" in Software. If the repository cannot be reached, Ubuntu's version is installed.
- Existing PostgreSQL 16 clusters keep running as they are; to move to 18, delete the databases, then remove and reinstall PostgreSQL.
- On new installs the panel's own database also comes with the newest stable PostgreSQL.
- The database server installation log now shows the package installation steps too.
