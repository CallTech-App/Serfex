An account moved from Plesk now gets a short name, and IP addresses can be read.

- **Account name:** the long system user name Plesk generates itself (for example `celiksocks.calltech._c2mbyoz2syf`) is no longer carried over. The account is created with a short name derived from the main domain (`celiksocks.shop` → `celiksocks`). This name can be changed on the "What the subscription holds" screen, and the Plesk name is shown next to it for reference. The name can be changed in cPanel moves too; the default is still the cPanel name.
- **IP addresses:** Plesk keeps the table as `IP_Addresses`; because Serfex asked for `ip_addresses`, an "IP addresses could not be read" warning appeared. Now both names are tried.
- **Clearer error message:** because `plesk db` writes MySQL errors to standard output, Serfex showed only "exit status 1". Now the error itself (for example "ERROR 1146 … doesn't exist") appears in the log and in the warning.
