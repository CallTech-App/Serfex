DNS records, databases and backups are now managed from inside the site too.

- **DNS records inside the site:** the site's "Domains and DNS" section now opens with the DNS records; adding and editing records, zone settings and DNSSEC are done without leaving the site. When a subdomain site's records are in the parent domain's zone, that zone is shown.
- **Sites whose DNS is elsewhere:** if the zone is not on this server (for example Cloudflare), the page says so and lists the A/AAAA records the site needs to open. If you want, "Create DNS zone" creates the zone in one click (Undo in the notification).
- **Databases and Backups inside the site:** these two sections open under the site's header with only that site's databases and backups. Server-wide destination and schedule settings stay in Backups in the main menu.
