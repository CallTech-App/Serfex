- Software and Services → PHP versions: components that are not installed now show the version that will be installed and the repository it comes from; the Install dialog shows the same information.
- Database servers are installed only in versions Servik supports: MySQL 9.7 LTS and 8.4 LTS (repo.mysql.com), MariaDB 12.3 LTS and 11.8 LTS (dlm.mariadb.com), PostgreSQL 18 (apt.postgresql.org). The default is the newest version on the list. The version can be chosen in the Install dialog and on the Databases → installation card. A new major version (for example PostgreSQL 19) joins the list only through a Servik update, after it has been tested.
- If the vendor's repository cannot be reached, the database installation stops and what was done is rolled back; Ubuntu's older version is not installed. Servers installed earlier (MySQL 8.0, MariaDB 10.11, PostgreSQL 16) stay on their version and keep getting minor updates.
