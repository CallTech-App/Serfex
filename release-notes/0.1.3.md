- First sign-in: `install.sh` now prints a one-time setup link at the end (valid for 24 hours, usable once). Whoever opens the link creates the first administrator account. If the link is lost, `sudo servik setup-url` on the server makes a new one. `--admin-email` keeps working as before for unattended installs.
- Setup wizard: server name and IP addresses, time zone and language, name servers (with a glue record reminder, the DNS server and your domain's zone), panel address (the server's name, a separate name, or only IP and port) and its certificate, notification emails, firewall, defaults for new sites and the update channel, backups. Every step can be put off with "Later"; it opens again from Settings → Setup wizard.
- Overview shows a "First-run setup" list until the wizard is finished. On servers updated from earlier releases, settings that were already made (name servers, panel certificate, notifications, firewall, remote backup destination) count as done.
- A full administrator's first sign-in to a new panel opens the wizard.
