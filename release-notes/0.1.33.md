- **Moving from cPanel**: Sites → **Move from another server**. A full backup of a cPanel account (`cpmove-user.tar.gz`, or `backup-…_user.tar.gz` taken with "Download a Full Account Backup" in cPanel) is uploaded, or large archives are copied to `/var/lib/serfex/backups/import/` and selected.
- Once the archive is read, before anything changes, it shows what is inside: sites (the main domain and every addon domain as separate sites, parked domains as aliases, subdomains with their folders), databases, mailboxes, DNS zones, valid certificates, and what will not be moved. The administrator chooses the sites, the parts and the customer (a new customer with the account's contact address, an existing customer, or no customer) and starts the move.
- The account is created with its cPanel user name; database names and file paths do not change. Old folder paths (`~/public_html`, `~/addon-domain.com`) are linked to their new places, and the rest of the home folder comes along too.
- Database users and mailboxes come with their old passwords. If a password uses a format this server cannot use, a new password is given; the database password is written to the site's configuration file (`wp-config.php`, `.env`…) and shown in the report (stored encrypted, deleted with "Forget passwords").
- DNS zones start with Serfex's records, and the old records that do not conflict are added; the old server's address is replaced with this server's. Valid SSL certificates are used until they expire.
- Domains that already exist here are skipped, and existing databases and users are not changed. Scheduled tasks, FTP accounts, PostgreSQL databases and remote MySQL access are listed in the report but not moved. The old server is not touched.
- Plesk accounts will be moved in a later release, by connecting to the old server over SSH.
