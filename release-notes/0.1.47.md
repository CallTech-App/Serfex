- New command: `sudo serfex change-email <old> <new>`. When the confirmation email sent to the new address does not arrive, it changes an account's email address on the server right away. Notification recipients, the Let's Encrypt address and the customer record move to the new address too, the pending change is cancelled, and it is written to the activity log.
- The pending email change box in Account details now says what to do "if it did not arrive". An administrator is shown a ready `serfex change-email` command; a customer is told to ask their administrator.
- The panel warns when the server's IPv4 address has no **reverse DNS (PTR)** record or the record does not point back to the server (Email settings, Settings → Notifications, pending email change). In that case Gmail and Outlook reject mail from the server with `550 5.7.25`, while the panel thought the mail was "sent". No warning appears when an SMTP server is configured.
