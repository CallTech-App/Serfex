The panel no longer starts answering "500 Something went wrong" after running for a few days, and notification e-mails sent through the server's own mail server arrive again.

- **What happened:** the panel's scheduler and queue workers ran with systemd's `NoNewPrivileges`. Under it Postfix's `sendmail` cannot write to the mail queue, and instead of failing it waits forever. Every scheduled run with something to tell the administrators by e-mail (a site stopped answering or came back, a certificate, a backup, a customer near a limit) hung on that message and never finished. Each stuck run kept its database connections, and once enough of them had gathered the panel's own PostgreSQL had none left: pages and their background refreshes answered 500 until the scheduler was restarted. Servers that send the panel's mail through an SMTP server (Tools & Settings → Notifications) were not affected.
- **Notification mail leaves again:** the scheduler and the workers no longer set `NoNewPrivileges`, like the panel's web side, which was always able to send (the test message, invitations, password links). Mail about sites that stop answering, certificates, backups, updates and customers' usage, which was silently never sent from the background, now goes out.
- **sendmail can no longer hold the panel:** a `sendmail` that has not finished within 30 seconds is stopped, and the notification records "The server's mail program (sendmail) did not answer within 30 seconds and was stopped." instead of waiting without end.
- **Stuck checks do not pile up:** the once-a-minute site availability check and Laravel background check are stopped when one is still running after 15 minutes, so a check that hangs for any other reason cannot use up the database connections either.
- **Existing servers:** the update rewrites the three panel services (`serfex-panel-queue`, `serfex-panel-backups`, `serfex-panel-scheduler`) and restarts them, which also ends the runs that are stuck now. No setting changes. Problems that were already open are not mailed again; new ones and the ones that go away are.
