- **Forgot password?** was added to the sign-in page. Administrators, customers and team members can set a new password with a one-time link sent to their email address. The link is valid for 60 minutes, works once, and only the newest one is valid.
- The email goes out the same way as the panel's notifications (this server's mail server or the SMTP server in Settings → Notifications) and in the person's own language. The page gives the same answer whether or not the address has an account; at most one link per minute and five per hour go to an address.
- When the new password is saved, all of the account's sessions are signed out and the person gets a notification email. If two-step verification is on, it is still asked at sign-in. Requests and resets are written to the activity log.
- If the panel cannot send email, the page says so and shows the new command on the server: `sudo serfex reset-password <email>` prints a reset link for any account.
