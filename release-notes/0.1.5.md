- Welcome page for new sites: the `public_html` folder of a newly created site (and of new subdomain folders) now gets Servik's default page as `index.html`. The page shows the domain, a "Sign in to the panel" button when the panel has a name, short notes for the site owner, the Laravel developer and the visitor, and a "What is Servik?" section. The default language is Turkish; the "English" link on the page switches it to English. When the customer uploads their own `index.html` or `index.php`, it takes this page's place. Files of existing sites are not touched.
