- The panel can no longer be opened inside a frame (iframe) on another site's page (clickjacking protection): every response sends `X-Frame-Options: DENY` and `Content-Security-Policy: frame-ancestors 'none'`. phpMyAdmin and Adminer still work with `SAMEORIGIN`.
- When the panel is opened with its own name and certificate, it sends HSTS (1 year); from then on the browser opens that name only over HTTPS. Subdomains are not included, so HTTP sites under the same domain are not affected. There is no HSTS when the panel is opened by IP address; if the panel certificate ever becomes invalid, the panel still opens at `https://IP:8443`.
- The headers are written to the panel's Nginx configuration with the update; you do not need to do anything else.
