- New **SnappyMail** webmail: Email → Email settings → **Webmail** now offers Roundcube, SnappyMail or Off (it can also be turned on from the SnappyMail row in Software → More). Roundcube stays the default. Only one webmail runs at a time and the address does not change (`https://<mail server>/`); the **Webmail** button in the panel opens the mailbox in the selected application in one click, without a password.
- Since SnappyMail has no Ubuntu package, Serfex downloads the version it has tested (2.38.2) from GitHub and checks its SHA-256 checksum. The release lives under `/opt/serfex/snappymail` and its data (settings, contacts) under `/var/lib/serfex/webmail/snappymail`. SnappyMail's admin panel is off; Serfex writes its settings. The address book is on, and the language is taken from the browser.
- When the application is switched, contacts and settings are not moved; each application's data stays on the server and is still there when you switch back.
- If a later Serfex update brings a newer SnappyMail, **Update** appears on the SnappyMail row in Software; the previous release is kept for rollback.
