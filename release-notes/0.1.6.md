- Name server IP addresses: the Name servers step of the setup wizard now has an IP address field next to both `ns1` and `ns2`. Left empty, the server's IP address is used (a single-server setup works as before); if a name server is on a second server or on the server's second IP address, type that address. The `ns1`/`ns2` A records in your domain's DNS zone and the glue reminder use these addresses.
- Domains & DNS → Server DNS settings: "Name server IP addresses" lets you change these addresses later; when they change, the A record in the name server's zone on this server moves to the new address too.
