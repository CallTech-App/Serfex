- Software and Services → PHP versions: while an installation, update or removal was running, the other buttons stayed disabled without saying why. Now the top of the page says which job is running and when it started; "Show progress" opens that job's steps. Database server installations and Servik updates are shown with the same note.
- Services → PHP versions: a "Check for updates" button and the time of the last check were added. A new PHP patch release (for example 8.4.13 → 8.4.14) appears without waiting for the nightly check and is installed with "Update" on its row.
- Services → Apache → Settings (when Apache was installed from Software): concurrent request limit (default 150) and request timeout (default 300 seconds). The configuration file is checked with `apache2ctl configtest` first; if Apache does not accept it, the previous settings stay. Every save can be reverted with "Undo".
- Services → PowerDNS → Settings: response cache (20 seconds), negative response cache (60 seconds), query logging (off) and zone transfer permission. If zone transfer permission is left empty, nothing is transferred to secondary name servers; when the IP addresses or networks of secondary name servers are entered here, they can copy your zones. Saving restarts PowerDNS (about 1 second); if it does not start with the new settings, the previous settings come back.
