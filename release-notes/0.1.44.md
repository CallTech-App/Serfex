- **Application templates.** Define your own Laravel application once in Settings → Application templates, then install it on any site in one step. Templates live only on this server, in the panel's database; nothing goes into the open-source code. Every installation is separate: its own code, database and `.env` file.
- There are two source types. **Git repository**: a repository picked from your connected Git account or a public one, a tag or a branch; Serfex installs and updates it and adds a separate read-only deploy key per site for a private repository. **Release package**: a zip attached to the latest release on GitHub, or a fixed https address; it is unpacked into the site's `app/` folder, the site root becomes `app/public`, and later updates are done by the application from its own admin panel.
- The template's page sets the database (a new MySQL/PostgreSQL database per site, SQLite, or none), the PHP version, the queue worker and scheduler, `.env` lines, questions asked at install (text, secret text, a file such as a licence), first-install commands and the first administrator account. Placeholders: `{site.url}`, `{customer.name}`, `{db.password}`, `{ask.KEY}`, `{file.KEY}`, `{random:32}` and others.
- Installation: Sites → Add site → **Application** (the site is created, a certificate is issued, then the application is installed) or Laravel → Install Laravel application → **From a template**. The installation can be followed live on the Laravel page. Serfex generates the first administrator's password and shows it once; passwords and secret answers are masked in the log.
- Updating (Git templates): change the template's tag, then update a single site from the Sites tab or all of them one after another with **Update all**. On every site: a database backup, the maintenance page, the new release and migrate; if the site does not come up, it returns to the previous release. Optionally, the remaining sites are not updated after the first failure.
- Customers cannot see templates by default; if "Customers can install it on their own sites too" is turned on for a template, they see only its name and description. Templates can be exported and imported as JSON (without the Git account and linked sites).
