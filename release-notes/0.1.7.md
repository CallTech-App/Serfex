- Fail2ban mail rules are now added automatically: when the mail server is installed after Fail2ban, the `dovecot` (IMAP/POP3) and `postfix-sasl` (SMTP sending) rules are written right away, and Fail2ban no longer has to be reinstalled. After updating to this release, missing rules are completed within a minute.
- Fail2ban rules follow the server every minute: when the mail server is removed the mail rules go away, and when the panel port changes the panel sign-in rule protects the new port. Every automatic change is written to Settings → Activity log as a "System" entry. A Fail2ban you stopped on purpose is not started meanwhile.
