A site's domain can now be changed from the panel, without fixing anything by hand.

- **Change domain:** from the ⋮ menu on the site's overview page, the site moves to another domain (example.com) or to a subdomain of a domain on this server (updates.example.com). The system account, files, databases and settings stay the same; before the change, the dialog shows one by one what will happen.
- **Files and permissions:** the folder is moved to the new name, and the old path stays as a link to the new folder; file owners and permissions do not change. Links such as storage are pointed at the new folder.
- **No downtime:** the Nginx, PHP-FPM, WAF and protected folder settings are written with the new name and switched over with a single reload. If a step fails, everything goes back to how it was and the site keeps running under its old name.
- **SSL:** if the new name points at this server, the Let's Encrypt certificate is issued before the change, so HTTPS is not interrupted. If it does not, the old name keeps opening with its own certificate, and the new name's certificate is issued by itself once DNS arrives.
- **Application settings:** the address and folder path in configuration files such as .env (APP_URL) and wp-config.php, and the addresses in the WordPress database, are updated; Laravel's configuration cache is rebuilt.
- **Background jobs:** queue workers, the scheduler, Redis (with its data), scheduled tasks and SFTP accounts restart with the new name. Laravel backups, deployment history and logs move to the new name.
- **DNS and the old name:** if the new name is under a zone on this server, the record is written to that zone; otherwise its own zone is created as for a new site. The old name can redirect to the new address (301), keep opening the site, or be removed.
- **Email:** email that has mailboxes stays on the old name and keeps receiving mail; email that is not in use moves to the new name.
- **Undo:** optionally, a backup of the site is taken before the change. The change can be reverted within 7 days with "Go back to the old name".
