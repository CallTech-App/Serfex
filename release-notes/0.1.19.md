- Since the repository is public, support for installing from a private repository was removed: the `install.sh --token` option, `SERFEX_GITHUB_TOKEN` and the `/etc/serfex/release-token` file are no longer used. Installing is one line: `curl -fsSL https://github.com/CallTech-App/Serfex/releases/latest/download/install.sh -o install.sh && sudo bash install.sh`.
- On servers installed earlier with a token, `/etc/serfex/release-token` is no longer read; you can delete it with `sudo rm /etc/serfex/release-token`.
- Personal data and real IP addresses in the documentation, design mockups and tests were replaced with example values (203.0.113.0/24, 2001:db8::/32, example.net).
