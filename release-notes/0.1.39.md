- **Moving from Plesk**: Sites → **Move from another server** → **Plesk server**. Without taking a backup, Serfex connects to the old Plesk server over SSH (root or a passwordless sudo user); it signs in with Serfex's SSH key or a password. The password is stored encrypted only until the transfer finishes; the server's SSH fingerprint is shown, and later connections require the same key.
- The subscriptions on the server are listed; the chosen subscription is first copied to this server (files, Maildir mailboxes, MySQL dumps, and from the Plesk database the domains, aliases, mail accounts, forwarders, DNS records and certificates). Nothing changes on the old server.
- Then the same preview, selection, move and report as the cPanel move follow. The main domain and every additional domain become separate sites, aliases come with their DNS zones as domain aliases, and subdomains are moved with their folders.
- Mailboxes come with their old passwords (read with Plesk's `mail_auth_view` tool and stored here only as SHA512-CRYPT). Database users come with their old password hashes; for a format this server cannot use, a new password is given and written to `wp-config.php`/`.env`.
- Domains without web hosting, mail for aliases, databases on another database server and PostgreSQL databases, scheduled tasks and extra FTP accounts are listed in the report but not moved. Files whose configuration still contains the old `/var/www/vhosts/` path are also pointed out.
