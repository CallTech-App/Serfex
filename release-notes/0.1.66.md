Email sent from outside now reaches mailboxes.

- **Incoming mail was blocked:** if the firewall was turned on before the mail server was installed (as in the setup wizard), the mail ports (25, 465, 587, 110, 995, 143, 993) were never added to the rules. Since the rules were not rewritten when email was installed later, mail from other servers was dropped on port 25. Sending was not affected, because sites and webmail connect from inside the server. The Security page also showed these ports as open.
- **Fix:** when the mail server (and the DNS server) is installed, the firewall rules are rewritten. Preset rules an administrator closed by hand stay closed.
- **Installed servers:** if the firewall is on during the update, its rules are rewritten once; the mail ports open by themselves, and you do not need to do anything else.
- **Security update:** the panel's Symfony components (http-foundation, http-kernel, routing) were upgraded to 7.4.23; this closes the vulnerabilities announced on November 4 involving client-chosen Host/proxy headers.
