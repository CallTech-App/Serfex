Saving the General tab of an application template no longer gives a 500 error.

- **Template saving fixed:** in Settings → Application templates → template → General tab, Save gave a 500 error every time ("preg_match(): Unknown modifier '/'"). The cause was a badly written validation pattern for the "Health address" field under Advanced; whatever you typed, the save blew up. The pattern was fixed; an invalid health address is now shown under the field with the message "The health address must be a path starting with /."
- **Protection against similar errors:** a test was added that compiles and tries every validation pattern in the panel; a broken pattern is now caught before it gets into a release. The other patterns were checked, and none is broken.
