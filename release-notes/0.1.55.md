Database dumps from MariaDB now load into MySQL.

- **Database import:** MariaDB 10.10 and later (11.x in particular) use collations in dumps that MySQL does not know (such as `utf8mb4_uca1400_ai_ci` and `utf8mb3_uca1400_ai_ci`). Because of this, a database moved from Plesk or cPanel, or dumped on a server with MariaDB, could not be loaded and failed with "ERROR 1273: Unknown collation". Now, when the server runs MySQL, these collations are turned into their closest MySQL equivalents while the dump loads (such as `utf8mb4_0900_ai_ci` and `utf8mb3_unicode_520_ci`). The "sandbox" line MariaDB 11 puts at the top of the dump, which MySQL does not accept, is skipped too. The data in the tables is not touched. When the server runs MariaDB, the dump is loaded as it is.
- **Plesk move:** some Plesk versions have no `public_ip_address` column in the IP addresses table; in that case addresses are read without that column, and the "IP addresses could not be read" warning no longer appears.
