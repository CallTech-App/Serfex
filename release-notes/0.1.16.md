- The mail server can be reinstalled with webmail (Roundcube). When the server had PHP 8.5, the installation was rolled back with a "Cannot redeclare function array_first()" error: Ubuntu's Roundcube 1.6 package does not work on PHP 8.5. Webmail now runs on the newest PHP 8.4 or older version on the server; the database upgrade and Roundcube's cleanup tasks use the same version. If an extension is missing for that version, the installation installs it too.
- Roundcube's cleanup tasks (old sessions, deleted records) now run on Servik's webmail database.
- Installing the mail server no longer installs an extra PHP-FPM service because of the Roundcube package.
- Removing the PHP version Roundcube depends on from Software is refused; otherwise apt removed Roundcube as well.
