- Overview was redesigned. At the top there is a server status card: a one-sentence summary, nine checks (Live monitor, Services, SSL, Backups, Security scan, Disk space, Customer packages, Your account, Serfex version) and, for every topic that needs attention, an explanation, "Ask AI" and a single action. If the server agent cannot be reached, a red line and "Try again" appear at the head of the card.
- Below it are CPU, memory, disk and network tiles (with a graph of the last 24 hours; for disk, an estimate of "full in X days at this rate"), hosting counts, the sites using the most resources, running services, the latest deployments of Laravel applications and recent activity (for full administrators only).
- While open, the page refreshes itself every 30 seconds. The Overview of customer accounts did not change.
