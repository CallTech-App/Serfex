PowerDNS, the DNS server for your domains, moves to the supported 5.1 series. Until now Serfex installed Ubuntu 24.04's package, PowerDNS 4.8.3, which PowerDNS stopped supporting in June 2026 and which gets no more security fixes (the October 2026 advisory, for example, was fixed only in 4.9.18, 5.0.8 and 5.1.5).

- **New servers:** the DNS server setup installs PowerDNS 5.1 from PowerDNS's own package archive (`repo.powerdns.com`, `noble-auth-51`), with its signing key checked and `pdns-*` packages pinned to that archive. If the archive cannot be reached during setup, Ubuntu's 4.8.3 is installed as before and the upgrade below is offered.
- **Existing servers are not changed on their own.** Software → Other components now lists PowerDNS with its version; **Upgrade version** moves it to 5.1. Server DNS settings shows the same offer next to the version.
- **How the upgrade works:** the archive is added first (if it cannot be read, nothing else changes). The installed 4.8 packages are downloaded and kept, and every zone, record set and DNSSEC key is saved. PowerDNS then stops and its database is copied, because PowerDNS 5 moves the database to a new format the moment it starts and 4.x cannot read it again. 5.1 is installed and started, every zone, record set and DNSSEC key is compared with what was saved, and the server must answer SOA queries on port 53. Any failed step puts the 4.8 packages and the copied database back.
- **What people notice:** the DNS server does not answer for about a minute; resolvers keep answering from their caches, and sites and email are not affected. DNSSEC keys stay the same, so DS records at registrars stay valid. Secondary name servers fetch the catalog zone once more, because PowerDNS 5 recounts it.
- **Undo:** for 7 days, **Go back to old version** puts 4.8 and the database copied before the upgrade back, and the panel writes every zone again so changes made after the upgrade stay. **Remove old version** deletes the kept copies earlier; after 7 days they go on their own.
- Later 5.1.x releases show as updates on the same page.
