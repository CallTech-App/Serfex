- Servik is now called Serfex. The panel, the command line (`serfex`), the server agent (`serfex-agent`), the services (`serfex-web`, `serfex-php`, `serfex-panel-*`), the folders (`/etc/serfex`, `/opt/serfex`, `/var/lib/serfex`), the panel's account and database, the environment variables (`SERFEX_*`) and the documentation use the new name.
- This release cannot be installed as a panel update on a server running Servik: because folders, services and accounts change, Serfex must be installed again on a clean Ubuntu server.
- For installs from a private repository, the token is now read from the `SERFEX_GITHUB_TOKEN` environment variable and kept in `/etc/serfex/release-token`.
