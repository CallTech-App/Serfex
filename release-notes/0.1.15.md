- Let's Encrypt certificates are now issued on a clean install. While PowerDNS was being installed, the server's DNS resolution moved from 127.0.0.53 to real DNS servers, but the Servik agent did not notice and kept asking 127.0.0.53 ("lookup acme-v02.api.letsencrypt.org on 127.0.0.53:53: server misbehaving"). The agent now sees the change immediately and retries within a few seconds if it cannot reach Let's Encrypt.
- Certificates that could not be issued because Let's Encrypt could not be reached at all (a network or DNS outage) are retried automatically within an hour instead of the next day. Certificates stuck with this error are requested again on the first attempt after the update.
- The PowerDNS installation no longer turns off the local resolver when the server has no external DNS server configured; it shows an error that says what to do instead.
