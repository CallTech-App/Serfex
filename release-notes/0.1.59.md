Everything about a site is now managed from inside that site; the site page was redesigned.

- **Shared site header and sections:** every page of a site (File Manager, FTP, PHP, SSL, Logs and the rest) has the same header at the top: the domain and its status, the customer, the Nginx and PHP version, the server IP, "Open site". Below it are the site sections: Overview, Files, Databases, Email, Domains and DNS, SSL and security, Backups, Logs. You move from one tool to another without leaving the site.
- **New Overview:** if there is a problem, it is shown in one line at the very top (for example "The site opens only over http" and "Get a certificate"). Below it is a summary of the web server, SSL, disk and the last backup; then the site tools in seven groups, each with an icon, a name and a status. Problem states are marked with an orange or red dot.
- **Email inside the site:** from the site's Email section, email is turned on in one click (Undo in the notification), and mailboxes, forwarders, mail traffic and mail settings are managed in the same place. Email in the main menu stays as the list of all domains on the server.
- On sites whose DNS zone is not on this server, "DNS records" now says "Zone not on this server" instead of "Soon".
