- Servik's repository moved to https://github.com/CallTech-App/Serfex. The install script, the CLI installer and the panel's update check now read releases from this repository.
- If a server installed with an earlier release still has the old Winchester37/Servik address in `/etc/servik/panel.json`, the update check looks at the new repository automatically; nothing has to be changed by hand.
- The GitHub token used for installing and updating from a private repository must be able to reach the new repository: create the token again for the CallTech-App organization and write it to `/etc/servik/release-token`.
