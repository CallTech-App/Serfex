- All panel addresses are in English: for example `/hizmetler?sekme=php` is now `/services?tab=php`, `/ayarlar/guncellemeler` is now `/settings/updates`, `/musteriler` is now `/customers`. The old Turkish addresses no longer open (404); update your bookmarks.
- The default language is English. On the setup page (`/install/…`) "The panel's language" is the first field; choosing Turkish switches the page to Turkish right away and the panel becomes Turkish. Servers installed with `install.sh --lang tr` still start in Turkish.
- The sign-in page now opens in the server's default language rather than the browser's; the Türkçe · English links at the bottom change it.
- `install.sh` no longer looks at the system's `LANG` value; without `--lang` the installation is done in English.
- The `serfex login` approval link is now `/cli/approve?code=…`.
