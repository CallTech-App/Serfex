- A full backup of a site is taken right before it is deleted: files, databases, email, DNS records and SSL certificates. The backup stays on this server and appears on the Backups page as "Before deletion".
- "Undo" in the notification that appears after deletion brings the site back from this backup immediately; later on, the site can also be recreated from Backups with "Restore" (if the site no longer exists, everything comes selected).
- Backups taken before deletion are kept for 30 days by default; the period can be changed in Backups → Schedule → "Backups before deletion" (1–365 days).
- An administrator can skip the backup by clearing the "Take a backup before deleting" box; customers cannot skip it. If there is no room on the disk for the backup, the delete dialog says so plainly.
- If the backup cannot be taken, the site is not deleted; the reason appears on the site's page. A backup is also taken first when a customer is deleted together with their sites and when deleting through the API (`?backup=0` and `serfex sites delete --no-backup` are for administrators only).
- In the backup list, the reason for a backup (Scheduled, Manual, Before restore…) now also appears in English in the English interface.
