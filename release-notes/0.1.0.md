- First public release: a web hosting panel for Ubuntu Server 24.04 and later, installed with a single command (`install.sh`); the panel, agent and command line are built for amd64 and arm64.
- Sites: a separate system user and PHP-FPM pool for every site, Nginx or Apache behind Nginx per site, PHP 8.1–8.5, deleting a site by typing its domain.
- Domains: subdomains, additional domains, domain and path redirects (301/302), custom error pages, Nginx/Apache directives for administrators, access and error logs that follow live.
- File Manager (uploads up to 2 GB, editor, zip, permissions, 7-day trash) and SFTP accounts locked to a folder.
- Scheduled tasks: cron jobs that run as the site user, with a time limit, overlap protection and run history.
- Statistics: visitors, pages, bandwidth, referrers, countries and bots; the data never leaves the server. Disk usage breakdown.
- DNS: its own authoritative DNS server (PowerDNS), zones created automatically when a site is added, a record template, zone file export.
- SSL: Let's Encrypt certificates (through the agent's own ACME client), wildcard certificates when DNS is local, renewal 30 days before expiry, HTTPS redirect, certificate upload.
- Email: Postfix, Dovecot, Rspamd and Roundcube in one step; SPF, DKIM, DMARC and client settings records created automatically; quotas, forwarding, autoresponders, catch-all, hourly sending limit, mail traffic.
- Databases: MySQL or MariaDB, with PostgreSQL alongside; prefixed databases and users, privileges, remote access rules, passwordless phpMyAdmin and Adminer, a backup before deletion.
- Laravel toolkit: install from a Git repository or with a starter kit, zero-downtime deployment, health check and automatic rollback, the last five releases, deployment hooks, push webhook.
- Laravel: pull request preview environments, .env editing and history, Artisan/Composer/npm commands, Tinker, queue workers, the scheduler, Horizon, Octane and Reverb processes.
- Laravel: logs, maintenance mode with an IP allow-list, application backups, a Redis instance per application, team members (owner, developer, read-only) and deploy keys for CI.
- Customers and plans: four preset plans, limits and features, quotas and warning emails, suspension, invitations with a sign-in link, signing in as a customer, a customer panel that shows only their own hosting.
- Live Monitor: CPU, memory, PHP workers, requests, disk, database and mail usage per site; a list of attacks, one-click IP blocking and temporary resource limits, the mail queue, 400 days of resource history.
- Servik AI: an assistant built on Claude that reads the server, explains the problem and fixes it with your approval; without approval only IP blocks and temporary limits, a monthly spending limit, a full transcript.
- Security: nftables firewall, ModSecurity WAF with per-site exceptions, malware and outdated software scanning, Fail2ban, a two-step verification policy, SSH settings, password-protected folders.
- Backups: the whole server or a single site, full and incremental, local disk, S3-compatible storage and SFTP, AES-256 encryption, selective restore, import, and rebuilding a server with `servik:restore-server`.
- Services: system services shown in groups, start/stop/restart with a configuration check, logs, Nginx/MySQL/Postfix settings; PHP versions, extensions and php.ini defaults.
- Software: install, update and remove optional components step by step; a failed step is rolled back, and a component in use cannot be removed.
- Settings: panel address, its certificate and a port change that reverts after 10 minutes, time zone, email and signed webhook notifications, administrator roles, API keys, an activity log you can undo from.
- Updates: one-click updates from the panel, a panel backup first, automatic rollback together with the database when the health check fails, returning to the previous version, stable and beta channels.
- Command line: `servik` for Linux and macOS; sign-in approved in the browser, sites, domains, DNS, SSL, email, databases, backups, services, customers and Laravel deployments; `--json` and CI support.
- REST API (`/api/v1`): sites, domains, certificates, DNS, email, databases, backups, customers, services and Laravel applications.
- Turkish and English interface: a server language and a language per person, emails in the recipient's language, Servik AI answers in the user's language.
- Known limits: a WordPress toolkit, an SSH terminal in the browser, Git deployment for non-Laravel sites, moving from another server, DNSSEC, secondary DNS and importing cPanel/Plesk backups come in later releases; releases are verified with SHA-256 but not yet signed.
